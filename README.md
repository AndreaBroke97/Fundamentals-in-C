# Fondamenti di C

Esercizi di linguaggio C svolti durante i miei studi, alla Steve Jobs Academy presso la sede di Catania: esercizi di base per imparare la programmazione, array, funzioni, calcolatrice e molti altri esercizi. Tra questi, il progetto per l'esame: un progetto gestionale per la gestione di un hotel.

---

## Sul contenuto di questa repository

Questa repository raccoglie il mio percorso di apprendimento del linguaggio C, dai primi esercizi di base fino ai progetti d'esame. Per questo motivo, non tutti i file rappresentano soluzioni definitive o prive di errori: alcuni sono esercizi completi e funzionanti, altri sono tentativi, bozze o versioni intermedie realizzate mentre imparavo un concetto nuovo.

Ho scelto di mantenere anche queste versioni incomplete perché documentano il percorso fatto, non solo il risultato finale: può capitare di trovare funzioni con qualche imprecisione, logica da rivedere o parti non ancora implementate. Fa parte naturale dell'apprendimento, e preferisco mostrarlo con onestà piuttosto che nasconderlo.

## Il progetto d'esame: gestione di un hotel

La cartella `07_hotel_management_exam` contiene il progetto più corposo del percorso: un archivio di camere d'albergo, gestito tramite un array di struct, con operazioni di inserimento, ricerca, aggiornamento, check-in, check-out e calcoli statistici (incasso teorico, conteggio per tipologia, prezzo medio).

Al suo interno sono presenti più versioni dello stesso progetto, che documentano le tappe successive di sviluppo: alcune sono fasi di lavoro con qualche funzione da correggere, altre sono versioni più mature e funzionanti. Anche in questo caso non le ho eliminate: raccontano il percorso, non solo l'arrivo.
